# Weekly Review

Create a Monday-style recap of what happened in your Second Brain in the last 7 days.

## Prerequisite

This skill depends on the default `second-brain` skill.
Install `second-brain` first, then add this skill.
It inherits core KB access, safety, and write-confirmation rules from
`second-brain`.

## Output shape

- `WhatCaptured`
- `KeyThemes`
- `OpenLoops`
- `BusinessImpact`
- `Top3Actions`
- `NextWeekFocus`

## Example prompts

- "Give me my weekly review"
- "What did I save and note this week?"
- "Create a Monday recap of my recent activity"
- "Summarize this week and tell me what to focus on next"
- "Give me investor signals from this week"
- "Summarize pipeline movement and follow-ups from this week"
- "Show lead and deal movement from this week"
