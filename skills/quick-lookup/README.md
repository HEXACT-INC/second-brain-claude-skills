# Quick Lookup

Get a fast synthesis for "what do I know about X?" across your KB.

## Prerequisite

This skill depends on the default `second-brain` skill.
Install `second-brain` first, then add this skill.
It inherits core KB access, safety, and write-confirmation rules from
`second-brain`.

## Output shape

- `ExecutiveSummary`
- `WhatKnown`
- `Evidence`
- `DecisionUse`
- `UncertainOrMissing`

## Example prompts

- "What do I know about Acme's renewal?"
- "What do I know about Jane Doe?"
- "Give me a quick lookup on our Stripe migration"
- "Summarize what I know about this topic from notes and contacts"
- "What do I know before signing this deal?"
- "What do I know about this investor relationship?"
- "What do I know about this property lead?"
