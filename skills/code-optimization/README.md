# Meeting Prep

Create a complete pre-call brief for a person or company using your KB data.

## Prerequisite

This skill depends on the default `second-brain` skill.
Install `second-brain` first, then add this skill.
It inherits core KB access, safety, and write-confirmation rules from
`second-brain`.

## Output shape

- `MeetingObjective`
- `WhoTheyAre`
- `RecentInteractions`
- `ContextSignals`
- `NegotiationLevers` (if relevant)
- `RiskFlags`
- `DesiredOutcome`
- `SuggestedAgenda`
- `QuestionsToAsk`

## Example prompts

- "Prep me for my meeting with Jane Doe tomorrow"
- "Build a pre-call brief for Acme Inc"
- "What do I know before this investor check-in?"
- "Give me a concise meeting brief for this contact"
- "Prepare me for a vendor negotiation call"
- "Prep me for a client renewal discussion"
- "Build a brief for a property-owner meeting"
